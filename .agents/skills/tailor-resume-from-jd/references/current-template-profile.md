每次生成前重新计算哈希。若不一致，说明用户已更新模板；以当前 `ResumeApp.tsx`、`data.ts` 和 `resume.css` 为准重新识别，禁止为了符合本档案而回退用户改动。

## 页面与结构

- 页面为 A4 纵向：`210mm × 297mm`；打印页边距为 0。
- `.resume-page` 内边距为上 `7mm`、左右 `10mm`、下 `6mm`，`overflow: hidden`。
- 内容为单栏；`.single-column-content` 顶部内边距 `4mm`，相邻栏目顶部间距 `2.15mm`。
- 外框距页面四边 `3.7mm`，四角交替使用深蓝和铜金色折角。
- 表头为正文加右侧证件照的网格，最小高度 `31.5mm`，右栏 `23mm`，列间距 `5.5mm`，左内边距 `4mm`。
- 栏目标题高度 `5.8mm`、图标方块 `5.4mm × 5.4mm`、间距 `2mm`、下边距 `.8mm`。方块内仅放原有 SVG 图标，不放文字。
- 条目列表左缩进 `2.65mm`；普通条目内边距为上下 `1.65mm`、左 `4.2mm`，左侧保留时间线和铜金节点。
- 原版在 Chromium 打印环境下约为 `794 × 1123px`，正文底部安全空间实测约 `47.8px`。


特殊文本使用以下字体规则：

| 元素 | 字体与字号 | 字重 | 行高 |
| --- | --- | --- | --- |
| 姓名 `.name-row h1` | `'Songti SC', 'STSong', serif`，`24pt` | `800` | `.88` |
| 表头眉题 `.resume-kicker` | `'SFMono-Regular', Consolas, monospace`，`6pt` | `700` | 简写属性默认值 |
| 英文姓名 | 同上等宽字体，`6.2pt` | `650` | 简写属性默认值 |
| 学生身份 | 默认字体，`6.2pt` | `800` | 继承 |
| 联系方式 | 默认字体，`6.2pt` | 继承 | 继承 |
| 技能标签 | 默认字体，`5.5pt` | `750` | `1` |

| 日期 | 等宽字体，`5.2pt` | `600` | 简写属性默认值 |
| 职位 `.entry-role` | 默认字体，`6.4pt` | `800` | 继承 |

所有元素的 `letter-spacing` 保持原计算值，不新增字距。字体加载后必须通过计算样式比对，而不是只核对 CSS 文本。

主页基准 PDF 实际嵌入 `Microsoft YaHei` 与 `Microsoft YaHei Bold`。当前 Linux 无头 Chromium 不具备这些字体，会把中文回退到 `WenQuanYi Zen Hei`，把西文回退到 `DejaVu Sans`；这种 PDF 不得作为正式交付，验证器会直接失败且不写入 PDF。优先在带有苹方/微软雅黑的 macOS 或 Windows 上运行脚本；只有无法更换环境时，才对基准页和候选页同时启用 `--normalize-cjk-fonts`，以 Noto Sans SC、Noto Serif SC 和 Roboto Mono 统一渲染。

## 加粗实现

加粗分成三类，不得混用或另建近似样式：

1. 条目标签：`<strong>标签：</strong>`，由 `.detail-list strong` 设置颜色 `#2e3637`、字重 `800`。
2. 岗位关键词：`<strong class="detail-emphasis">短语</strong>`，字重 `900`、颜色继承，并使用 `-webkit-text-stroke: .12px currentColor`。只包裹短语，不包裹标点或整句。
3. 固定身份信息：职位和项目角色分别沿用 `.entry-role` 与 `.project-inline-role` 的原样式；学校、单位和项目名称仍使用原有 `h3`，不额外嵌套强调标签。

教育经历中的“保研至合肥工业大学”等关键事实，以及实习、项目和校园经历中与 JD 直接对应的动作、工具和成果，使用第二类强调。强调短语必须来自真实内容，并保持原组件 `EmphasizedDetail` 的输出结构。

## 表头合同

- DOM 顺序固定为眉题、姓名行、联系方式、技能标签、证件照。
- 眉题仍为 `OPERATIONS & BUSINESS`；姓名、英文名、学生身份、联系方式、地点和技能标签读取 `src/resume/data.ts` 的当前值。
- 联系方式使用原 Lucide 图标，证件照使用同一源图及裁切参数。
- 用户未明确授权时，候选表头的规范化文本和截图必须与初始简历完全一致。

## 基准选择器

- 浏览页基准：`.screen-resume .resume-page`
- 打印基准：`.print-resume .resume-page`
- 独立候选页：`.resume-page`
- 表头：`.identity-header`

使用技能自带验证器比较字体、布局、表头和单页填充。当前模板的常规验收底边范围可设为 `20–90px`；候选应接近基准的 `47.8px`，但不能通过改 CSS 追求数值一致。
